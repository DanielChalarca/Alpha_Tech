# Alpha Tech – Smart Pet Collar & Social Platform

Alpha Tech is an integrated system consisting of a **smart collar for pets** and a **social-style web platform**.  
This project combines **IoT**, **real-time analytics**, and **community interaction** to enhance the safety, health, and connectivity of pets and their owners.

## 🚀 Project Overview

Alpha Tech provides:

- A **smart collar** built with **ESP32** and multiple sensors to track pet activity, health indicators, geolocation, and environmental conditions.
- A **web platform** that functions like a **social network**, allowing users to:
  - View and share their pet’s statistics.
  - Connect with **verified veterinarians** who have professional profiles.
  - Access health insights, alerts, and community posts.

The system integrates **hardware**, **backend services**, **frontend UI**, and **data analytics** into a unified experience for pet owners.

## 🧩 Architecture Overview

**ESP32 → NestJS Backend → Database → React Frontend → Users / Veterinarians**

Sensor data is sent from the ESP32 to the backend, processed and analyzed, and displayed in real time in the user interface.
